# Dashboard

This folder will contain the monitoring and explanation interface.

## Planned views

- score dashboard by ticker and timestamp
- evidence panel with citations
- source quality and freshness metrics
- risk and veto summary
- model performance and drift monitoring
- paper-trading summary and drawdown monitor

## Design goals

- Simple navigation
- Explainability first
- Audit-friendly logs
- Clear state transitions: analysis, paper, live-disabled
